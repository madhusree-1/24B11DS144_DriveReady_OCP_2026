# Agentic AI Workshop – Day 1

## Overview
Day 1 of the Agentic AI Workshop focused on setting up an LLM-powered chatbot using Groq and LangChain, exploring basic chatbot functionality, and understanding Prompt Guard.

## Topics Covered
- Introduction to LLMs and chatbot development
- Setting up Groq with LangChain
- Chatbot creation using `ChatGroq`
- System prompts and chatbot behavior
- Testing chatbot responses
- Introduction to Prompt Guard
- Exploring `meta-llama/llama-prompt-guard-2-22m`

## Technologies Used
- Python
- LangChain
- Groq
- Google Colab
- Prompt Guard

## Implementation
- Configured the Groq API.
- Created a chatbot using LangChain and Groq.
- Defined a system prompt to control chatbot behavior.
- Tested the chatbot with different user queries.
- Explored Prompt Guard for prompt-injection detection.

## Learning Outcomes
- Understood the basics of LLM-powered chatbots.
- Learned how to connect an LLM using Groq.
- Explored system prompts and chatbot customization.
- Gained an introduction to prompt security using Prompt Guard.
